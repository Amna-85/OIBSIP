# 🚀 OIBSIP - Python Development Internship Tasks

Welcome to my repository for the **Python Development Internship** at **Oasis Infobyte (OIBSIP)**. 

This repository contains a collection of practical Python projects I built during my internship. Each project focuses on different aspects of software development, including GUI design, API integration, automation, and database management.

---

## Projects Overview

Here are the tasks I have completed so far:

### Task 1: Voice Assistant
An interactive voice-controlled assistant that processes spoken commands and automates digital tasks.
- **Key Skills:** Speech Recognition, Audio Processing.

### Task 2: BMI Calculator
A health tracking application that calculates Body Mass Index based on user inputs and provides health category feedback.
- **Key Skills:** Python Logic, GUI Development (Tkinter), Database Integration (SQLite).

### Task 3: Advanced Weather App
A graphical weather application that fetches and displays real-time weather data and a 5-day forecast using the OpenWeatherMap API.
- **Key Skills:** RESTful APIs, JSON Parsing, Tkinter GUI, Error Handling.
